# bioreactor_mini_twin

CHO 유가식 배양을 대상으로 한 미니 디지털 트윈 개인 프로젝트.
목표는 **데이터 → 모델 → 평가 → 대시보드 → 검증 문서**까지 이어지는 전체 시스템을 직접 구축하는 것이다.

## 시스템 구조

```
[1] 데이터 계층   가상 공정 생성기 / 공개 데이터 로더 → 표준 형식(batches.csv)
       ↓
[2] 모델 계층     A 기계론 · B 하이브리드(NN) · D 하이브리드(GP) · E PINN  (공통 fit/predict)
       ↓
[3] 평가 계층     학습/검증 분할, RMSE, 외삽 시험, 데이터 양별 비교 → 결과 자동 저장
       ↓
[4] 대시보드      Streamlit: 공급 조건 슬라이더, 모델 선택, 경고, 비교 그래프
       ↓
[5] 검증 문서     FDA AI 모델 신뢰성 평가 7단계 틀 적용, [3]의 결과를 근거로 인용
```

## 진행 현황

| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 저장소 뼈대, 가상 공정 생성기 | ✅ |
| 1 | 모델 A(기계론) + 평가 계층 | ⬜ |
| 2 | 대시보드 최소 버전 | ⬜ |
| 3 | 검증 문서 초안 | ⬜ |
| 4 | 모델 B·D·E 추가, 공개 데이터 적용 | ⬜ |

## 폴더


## 가상 공정 모델

| 상태 | 의미 | 단위 |
|---|---|---|
| X | 생세포 밀도 (VCD) | 1e6 cells/mL |
| G | 포도당 | mM |
| L | 젖산 | mM |
| P | 항체 역가 | mg/L |
| V | 배양 부피 | L |

- 성장: Monod 식 + 젖산 저해
- 포도당 소모: Pirt 식 (성장 + 유지)
- 젖산 생성: 포도당 소모에 비례, 포도당이 높을수록 증가
- 항체 생산: Luedeking-Piret 식
- 공급: 연속 공급 또는 24시간 간격 볼루스. 샘플은 공급 직전에 채취한다고 가정.

> 계수는 그럴듯한 범위로 직접 정한 **예시값**이며, 특정 논문이나 실제 공정 데이터가 아니다.

## 데이터 형식 (`data/<source>/`)

| 파일 | 내용 |
|---|---|
| `batches.csv` | 측정 데이터 (24시간 간격, 노이즈 포함) — `batch_id, time_h, X, G, L, P, V` |
| `truth.csv` | 정답 곡선 (1시간 간격, 노이즈 없음) — 가상 데이터에만 있음 |
| `design.csv` | 배치별 공급 조건 |
| `meta.json` | 정답 계수, 노이즈 설정, 단위, seed |

기본 설계: 회분식 2 + 연속 공급 5 + 볼루스 4 = 11개 배치, 14일.

## 알려진 한계

- 유가식 배치는 대부분 포도당 제한 상태라 측정 포도당이 0 근처에 머문다. Ks 같은 계수는 데이터로 잘 정해지지 않을 수 있다 (보정 단계에서 확인).
- 온도·pH·용존산소 효과, 젖산 소모, 당쇄 등 품질 특성은 포함하지 않았다.
